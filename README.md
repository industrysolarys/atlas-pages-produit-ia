# Atlas · ta créateur de pages produit IA

Une équipe Solarys Academy : Atlas crée ta page produit Shopify en copiant la page d'un concurrent qui vend déjà.

- **Première fois ?** Suis le [guide d'installation](https://app.industrysolarys.com/kit-lancement/atlas).
- **Créer une page :** lance Atlas avec le bouton du guide, colle le lien de la page concurrente, et laisse-toi guider.
- **Mises à jour :** rien à faire, tu utilises toujours la dernière version de Atlas.
